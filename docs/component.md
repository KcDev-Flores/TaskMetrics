# Component: Reglas de Operación y Historias de Usuario

## Historias de Usuario
1. **HU-01 (Registro Post-Sprint):** Como líder de estudio, al finalizar cada *meeting weekend* de un sprint, quiero registrar las tareas completadas por cada programador para alimentar el sistema.
2. **HU-02 (Cálculo Automático):** Como líder de estudio, quiero que el sistema calcule de inmediato el total acumulado de tareas y el porcentaje actual de cada integrante sin modificar mis asignaciones manuales.
3. **HU-03 (Transparencia para el Equipo):** Como programador del mod, quiero poder consultar en cualquier momento mi porcentaje de participación actual basado en mi esfuerzo real en los sprints completados.
